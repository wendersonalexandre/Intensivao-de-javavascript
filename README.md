Durante o intensivão, desenvolvi **4 projetos**, explorando diferentes conceitos e tecnologias.

---

## 📌 Projetos

---

### 1. 🎧 Audiobook

**Descrição:** Player de áudio interativo que permite ouvir capítulos de um livro, com controles de **play, pause e troca de faixas**.  
**Foco:** Manipulação do DOM e eventos de mídia.  
**Tecnologias usadas:** HTML, CSS, JavaScript

![Audiobook](imagens%20projetos/foto-projeto-audiobook.png)


### 2. ⌚ Réplica do Site do Apple Watch

**Descrição:** Réplica do site oficial do Apple Watch, com layout responsivo e **navegação interativa, permitindo explorar o produto, recursos e modelos de forma visualmente similar ao site original**.<br>
**Foco:** Estruturação com HTML semântico, estilização avançada com CSS e efeitos de interação. <br>
**Tecnologias usadas:** HTML, CSS, JavaScript

![Audiobook](imagens%20projetos/foto-projeto-apple.png)


### 3. 📱 Cardápio Digital

**Descrição:** Aplicação web que apresenta um cardápio interativo, permitindo visualizar pratos, preços e descrições de forma organizada e atrativa, com destaque para imagens e categorias de alimentos. <br> 
**Foco:** Manipulação do DOM, componentes React e exibição dinâmica de conteúdos.  <br>
**Tecnologias usadas:** HTML, CSS, JavaScript, React e Vite

![Audiobook](imagens%20projetos/Foto-projeto-cardapio.png)


### 4. 🤖 Chatbot Inteligente

**Descrição:** Aplicação de chatbot interativo que se comunica usando a **API do ChatGPT, permitindo conversas inteligentes e em tempo real. O projeto apresenta interface moderna e responsiva, com gerenciamento de estado eficiente e carregamento rápido**.  <br>
**Foco:** Integração com APIs externas, desenvolvimento com React, TypeScript e bundler Vite, além de componentes reutilizáveis e estilização com Lovable.  <br>
**Tecnologias usadas:** React, TypeScript, Vite, Lovable, ChatGPT API.

![Audiobook](imagens%20projetos/imagem-projeto-chatbot.png)
